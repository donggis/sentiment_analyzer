# 현재 구조

개인 관리자 한 명만 쓰는 Flask 앱입니다. 로그인하면 서버가 세션 번호를 데이터베이스에 저장하고, 브라우저 쿠키에는 그 번호만 둡니다. 비밀번호는 해시와만 비교합니다. 글쓰기 요청에는 CSRF 토큰이 필요합니다. 로그인 실패는 데이터베이스에 적어 15분에 5번을 넘으면 잠시 막습니다.

수집은 YouTube Data API로 채널 하나를 읽습니다. 기본 채널은 `https://www.youtube.com/@jangpm`입니다. 업로드 재생목록, 영상, 댓글, 답글을 페이지 단위로 저장하고, 다음 페이지 토큰을 작업 행에 남깁니다. 같은 댓글 ID는 한 번만 저장합니다. 중간에 끊기면 같은 작업으로 이어 받습니다. 댓글이 꺼진 영상은 표시만 하고 다음 영상으로 넘어갑니다.

주제는 기본적으로 이 서버 안에서 자주 같이 나오는 단어로 묶습니다. `ENABLE_EXTERNAL_AI=true`가 아니면 댓글을 외부 AI로 보내지 않습니다.

데이터는 SQLite 파일입니다. Fly에서는 볼륨 `/data/app.db`에 둡니다. 백업과 복구는 `docs/DEPLOYMENT.md`에 있습니다.

예전 회원 가입, Google 로그인, Stripe, 문의 메일은 404로 막혀 있습니다.
